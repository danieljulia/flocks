flocks.js

Llibreria de live coding de flocs (boids) per sobre de p5.js + p5.sound. Pensada per escriure poc i veure resultats immediats.

Com funciona l'entorn

L'aplicació (index.html) carrega p5.js, p5.sound, la llibreria (flocks.js) i un mini-editor (editor.js). El codi que escrius a l'editor es divideix en dues funcions:

init()s'executa un cop cada vegada que executes (Ctrl/Cmd+Enter). Aquí es creen o es modifiquen els flocs.
live()s'executa a cada frame. Aquí es dibuixa i es modula.

Ctrl/Cmd+Enter executa els canvis sense reiniciar Ctrl+E amaga/mostra l'editor h referència ràpida en pantalla

Important: no facis servir let/const al nivell superior; declara variables globals planes (f = flock(...)) perquè el re-run no peti.

Crear un floc

f = flock()        // 20 ocells, ja es veu i ja reacciona a la música
f = flock(50)      // amb 50 ocells
f.add(10)          // afegeix 10 ocells en calent
f.remove(10)       // en treu 10

Tots els mètodes són encadenables:

f = flock(40)
  .col('#ff5c8a')   // color (nom, hex o color() de p5)
  .rad(4)          // radi dels cercles
  .spd(2.5)        // velocitat base (i màxima)

Comportament del floc

Cada ocell combina les tres regles clàssiques dels boids més una deriva de soroll Perlin que els dona organicitat:

.per(140)radi de percepció: fins on veu els veïns
.coh(1.8)cohesió: atracció cap al centre del grup
.ali(2)alineació: seguir la direcció dels veïns
.sep(2)separació: no xocar
.wnd(0.3)deriva de soroll (0 = boids purs)
.nsc(0.005)escala espacial del soroll (petit = camps suaus i grans)

Els ocells fan wrap-around: quan surten per una vora, tornen per l'oposada.

Direcció principal (camp de soroll)

Pots donar al floc una direcció dominant que segueix un camp de soroll:

f.dir(0, 0.2)        // cap a la dreta, gairebé en línia recta
f.dir(QUARTER_PI, 1) // diagonal, camp molt variable
f.dirOff()          // la desactiva

El primer paràmetre és l'angle en radians; el segon és la variabilitat: amb 0 els ocells van gairebé rectes; amb 1 el camp els desvia molt. Un tercer paràmetre opcional regula la força de l'ajust (1 per defecte).

Dibuix: cercles o línia contínua

f.linia(true)   // en lloc de cercles, traç continu

Amb linia(true) cada ocell dibuixa una línia entre la seva posició anterior i l'actual, amb un gruix igual al diàmetre del cercle. Combinat amb una estela llarga (trail(0.02)) genera traços que es fonen suaument.

Reactivitat al so

La llibreria escolta el micro i normalitza 4 senyals (0..1, amb porta de soroll):

bass()baixos (20–800 Hz)
mid()mitjans (800–2600 Hz)
treble()aguts (2,6–14 kHz)
amp()volum general

Per defecte cada floc ja reacciona sol: el radi batega amb els baixos i la velocitat amb els aguts. Es regula amb:

.rg(3)sensibilitat del radi als baixos
.sg(4)sensibilitat de la velocitat als aguts
.calm()desactiva la reacció automàtica

Per lligar qualsevol paràmetre a qualsevol banda, fes servir react(prop, fn, amt), on prop pot ser 'r' (radi), 'sp' (velocitat) o 'wnd' (deriva), i fn qualsevol funció que retorni un nombre:

f.react('r',   mid,    10)   // el radi creix amb els mitjans
f.react('sp',  bass,   2)    // la velocitat, amb els baixos
f.react('wnd', treble, 1.5)  // la deriva, amb els aguts
f.react('r',   () => mouseX / width, 20) // o el que vulguis

amt és quant s'hi suma quan el senyal val 1. Pots apilar diverses crides react() sobre el mateix floc. Amb soundMeter() veus les barres de so per calibrar a ull.

Pantalla i estela

trail(0.05)rastre: 0 = infinit, 1 = sense rastre (crida'l dins de live())
fade()pinta el fons amb l'estela actual (ja ho fa el draw de l'editor)

Exemples

Enganxa qualsevol d'aquests blocs sencers a l'editor i prem Ctrl/Cmd+Enter.

1 · Riu de tinta — traç continu i direcció gairebé recta

function init() {
  riu = flock(40)
    .col('#5cd6ff')
    .rad(3).spd(2)
    .per(60).ali(2).coh(0.5)
    .dir(0, 0.15)    // corrent cap a la dreta, quasi lineal
    .linia(true)     // traç continu en lloc de cercles
    .calm()          // sense reacció al so
}

function live() {
  trail(0.02)        // estela molt llarga: les línies es fonen a poc a poc
  riu.draw()
}

2 · Bombola de so — tot lligat a la música

function init() {
  bombolla = flock(30)
    .col('#ff5c8a')
    .rad(5).spd(1.5)
    .per(120).coh(2).sep(2.5)
    .rg(4)                      // radi ← baixos (auto)
    .react('sp', mid, 2)        // velocitat ← mitjans
    .react('wnd', treble, 1.5)  // deriva ← aguts
}

function live() {
  trail(0.05 + amp() * 0.2)     // com més volum, menys rastre
  bombolla.draw()
}

3 · Tempesta — camp de direcció molt variable

function init() {
  vent = flock(80)
    .col(color(255, 170))            // blanc semitransparent
    .rad(1.5).spd(3)
    .per(50).ali(1.5).sep(2)
    .wnd(0.2)
    .dir(QUARTER_PI, 0.9)            // diagonal, camp molt trebolat
    .sg(5)                           // accelera fort amb els aguts
}

function live() {
  trail(0.1)
  vent.draw()
  soundMeter()                       // barres de so per calibrar
}

.col(c) .rad(r) .spd(s)color · radi · velocitat
.per .coh .ali .sep .wnd .nscregles del floc i soroll
.dir(a, v) .dirOff()direcció principal i variabilitat
.linia(true)línia contínua en lloc de cercles
.rg .sg .calm() .react(p, f, a)reactivitat al so
.add(n) .remove(n)ocells en calent
trail(a) fade() soundMeter()pantalla i so
bass() mid() treble() amp()senyals d'àudio (0..1)
