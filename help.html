flocks.js

A live coding library for flocks (boids) built on p5.js + p5.sound. Write a little, see results right away.

Your first flock

This is all you need. Paste it into the editor and press Ctrl/Cmd+Enter:

function init() {
  f = flock()      // 20 birds
}

function live() {
  f.draw()
}

Every new flock starts with a random look and behavior (radius, speed, color, strokes, gap, sync, wild, see), picked inside the ranges of flocks.config.js. Then you change whatever you want: flock(20).rad(1).col('red'). No sound until you add it.

Now add things one at a time, running after each change:

function init() {
  f = flock(30)
    .col('#5cd6ff')     // 1. a color
    .gap(25).sync(0.8) // 2. birds stick together
    .r('rad', bass, 4) // 3. they grow with the bass (click once to turn on the mic)
}

How the environment works

Your code has two parts:

init()runs once every time you run the code. Create or change flocks here.
live()runs every frame. Draw here.

Ctrl/Cmd+Enter runs the changes without restarting Ctrl/Cmd+E hides/shows the editor h quick reference on screen

Important: don't use let/const at the top level; write plain globals (f = flock(...)) so running again doesn't break.

Running again keeps the birds

When you run again, each flock() reuses the flock it created last time: the settings start from the defaults and take your new code, but the birds stay where they are and nothing jumps. Flocks are matched by order (first call ↔ first flock). If you want to reorder your code freely, give them a name:

a = flock('river', 40)   // always the same flock, wherever this line is
b = flock('dust', 100)

Changing the number of birds adds or removes only the difference. To start from scratch, change the name or reload the page.

Look

All methods are chainable:

f = flock(40)
  .col('#ff5c8a')   // color (name, hex or p5 color())
  .rad(4)          // circle radius
  .spd(2.5)        // base (and max) speed
  .line()          // strokes instead of circles

With line() every bird draws a stroke from its previous position to the current one, as thick as the circle. With a long trail (trail(0.02)) the strokes melt together. line(false) goes back to circles.

Behaviour

Birds drift on a Perlin noise field. The two flocking rules start at a random value; gap(0) and sync(0) turn them off:

.gap(25)comfortable distance in px: closer they push away, farther they pull (0 = off). 12 tight swarm, 60 airy
.sync(0.8)fly the same way as neighbors (0..1)
.wild(0.3)improvisation (0 = none, 1 = lots)
.see(100)how far each bird sees its neighbors, in px
.nsc(0.005)noise scale (small = big, smooth currents)

Birds wrap around: when they leave through one edge they come back through the opposite one.

Main heading

f.dir(0, 0.2)        // to the right, almost a straight line
f.dir(QUARTER_PI, 1) // diagonal, very wild field
f.dirOff()          // turn it off

First parameter: angle in radians. Second: variability, from 0 (almost straight) to 1 (very wild). An optional third one sets how strongly they steer (1 by default).

Sound

The library listens to the mic and gives you 4 signals from 0 to 1:

bass()low (20–800 Hz)
mid()mid (800–2600 Hz)
treble()high (2.6–14 kHz)
amp()overall volume
beat()a pulse on every bass hit

The mic turns on with your first click or key press (browsers require it).

To make a flock react, use r(what, signal, times):

f.r('rad', bass,   2)    // radius: x1 in silence → x2 with full bass
f.r('spd', mid,    1.5)  // speed: up to x1.5 with the mids
f.r('wild', treble, 3)   // improvisation: up to x3 with the highs
f.r('rad', () => mouseX / width, 2) // any function works

what is the name of the setter you want to move: 'rad', 'spd', 'wild', 'see', 'gap' or 'sync'. times is the maximum multiplier: in silence nothing changes, at full signal the value is multiplied by times. Below 1 it shrinks instead: r('rad', bass, 0.5). You can stack several r() calls. calm() removes them all.

Ranges: from a value to another

Give two numbers instead of one and the signal moves the value between them, ignoring the setter:

f.r('rad', bass, 2, 20)   // 2 in silence → 20 with full bass
f.r('gap', mid, 80, 12)   // the flock tightens when the mids come in

Ranges also work when the base value is 0, where multiplying does nothing (a range also works if gap or sync is 0).

Color

The color reacts through four props, in HSB: 'hue' (0–360), 'sat' and 'bri' (0–100), 'alpha' (0–255). Ranges are the natural way to use them:

f.r('hue', mid, 180, 320)   // cyan → magenta with the mids
f.r('alpha', amp, 40, 255)  // transparent in silence, solid when loud
f.r('bri', beat, 3)         // flash on every hit

Hue and saturation do nothing visible on white or grey: give the flock a color first.

Smooth signals and beats

bass.smooth(0.9)     // smoothed: 0 = raw, 0.99 = very slow
beat()               // 1 on every bass hit, then fades out
mid.beat(0.5)        // pulse when mid goes over 0.5
treble.beat(0.6, 0.95) // slower fade
sig(() => mouseX / width).smooth(0.95) // any function can be a signal

Use them anywhere a signal goes: f.r('rad', bass.smooth(0.9), 4), f.r('spd', beat, 3). Create smoothed or beat signals inside init() (not in live()), because each one keeps its own memory.

soundMeter() shows the sound bars so you can calibrate by eye.

Screen

trail(0.05)trail: 0 = endless, 1 = none (call it inside live())
fade()paints the background with the current trail (the editor already does it)
.add(10) .remove(10)add or remove birds on the fly

Examples

Paste a whole block into the editor and press Ctrl/Cmd+Enter.

1 · Ink river — strokes and an almost straight heading

function init() {
  river = flock(40)
    .col('#5cd6ff')
    .rad(3).spd(2)
    .see(60).sync(0.9).gap(30)
    .dir(0, 0.15)    // current to the right, almost straight
    .line()          // strokes instead of circles
}

function live() {
  trail(0.02)        // very long trail: strokes fade slowly
  river.draw()
}

2 · Sound bubble — everything tied to the music

function init() {
  bubble = flock(30)
    .col('#ff5c8a')
    .rad(5).spd(1.5)
    .see(120).gap(35)
    .r('rad', bass, 5)        // radius up to x5 with the bass
    .r('spd', mid, 2)         // speed up to x2 with the mids
    .r('wild', treble, 3)     // improvisation up to x3 with the highs
    .r('hue', mid, 300, 400)  // pink → orange with the mids
}

function live() {
  trail(0.05 + amp() * 0.2)   // louder = shorter trail
  bubble.draw()
}

3 · Storm — a very variable heading field

function init() {
  wind = flock(80)
    .col(color(255, 170))            // semi-transparent white
    .rad(1.5).spd(3)
    .see(50).sync(0.7).gap(15)
    .wild(0.2)
    .dir(QUARTER_PI, 0.9)            // diagonal, very turbulent
    .r('spd', treble, 6)             // speed up to x6 with the highs
}

function live() {
  trail(0.1)
  wind.draw()
  soundMeter()                       // sound bars to calibrate
}

4 · Three flocks — the full demo

function init() {
  giant = flock(25).col('#ff5c8a').rad(4).spd(1.5)
    .gap(40).see(140).wild(0.15)
    .r('rad', bass, 4)

  smalls = flock(60).col('#5cd6ff').rad(2.5).spd(2.5)
    .gap(12).sync(0.9).see(50)
    .r('spd', treble, 5)

  mist = flock(30).col(color(200, 35)).rad(5).spd(0.8)
    .gap(30).sync(0.4).see(90).wild(0.4)
    .r('rad', bass, 2.5)
}

function live() {
  trail(0.05 + bass() * 0.4)   // the kick "wipes" the screen
  mist.draw()
  giant.draw()
  smalls.draw()
}

Quick reference

flock(n)new flock of n birds (default 20), random look and behavior
flock('name', n)named flock: reused across runs wherever it is in the code
.col(c) .rad(r) .spd(s)color · radius · speed
.line(on)strokes instead of circles
.gap(px) .sync(x)comfortable distance · fly the same way
.see(px)how far each bird sees
.wild(x) .nscimprovisation and its noise scale
.dir(a, v) .dirOff()main heading and its variability
.r(what, signal, x) .calm()react to sound: up to ×x (×1 in silence)
.r(what, signal, min, max)react to sound: from min (silence) to max (loud)
'hue' 'sat' 'bri' 'alpha'color props for r()
bass.smooth(k) bass.beat(t) sig(fn)smoothed signals, pulses, custom signals
.add(n) .remove(n)birds on the fly
trail(a) fade() soundMeter()screen and sound
bass() mid() treble() amp() beat()audio signals (0..1)
